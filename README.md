## 🎨 English

### What is NovaUI?

NovaUI is a modern, lightweight WinForms control library with a **built-in icon system** that embeds **26 icon packs (9,000+ icons)** directly into the assembly — no external files, no installation needed.

### ✨ Features

- 🎯 **Drop-in replacement** — `FTextBox`, `FButton`, and more with modern styling
- 🖼️ **9,000+ embedded icons** across 26 packs (Devices, Brands, FALCON, Food, Medical...)
- 🔍 **Built-in icon picker** — search, browse, and select icons from the Visual Studio Designer
- 🎨 **Rounded corners, gradients, RTL support** — designed for modern apps
- ⚡ **Zero configuration** — icons work out of the box
- 📦 **Single DLL** — 2.5 MB, no dependencies
- 🌍 **RTL/LTR ready** — perfect for Arabic and Hebrew UIs

### 🚀 Installation

```powershell
Install-Package NovaUI.WinForms
```

Or via .NET CLI:

```bash
dotnet add package NovaUI.WinForms
```

### 📖 Quick Start

1. Add a `FTextBox` or `FButton` to your form.
2. In the **Properties** window, find `IconGlyph`.
3. Click the **`...`** button → icon picker opens.
4. Pick any icon → it's applied automatically.

That's it. No code, no manual setup.

## 🌍 العربية

### ما هي NovaUI؟

NovaUI مكتبة كنترولات WinForms حديثة وخفيفة مع **نظام أيقونات مدمج** يحوي **26 حزمة (9,000+ أيقونة)** داخل ملف DLL — بدون ملفات خارجية، بدون تثبيت.

- 🎯 **بديل مباشر** — `FTextBox`، `FButton`، وغيرها بتصميم عصري
- 🖼️ **9,000+ أيقونة مدمجة** في 26 حزمة (Devices, Brands, FALCON, Food, Medical...)
